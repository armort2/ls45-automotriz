# LS45 Automotriz - Proyecto Final Diseño Web

Sitio web desarrollado para **LS45 Automotriz**, automotora dedicada a la compra y venta de vehículos, consignación, crédito automotriz y seguro automotriz.

El proyecto corresponde al examen final de la asignatura **Diseño Web**. Se trabajó a partir del template **Oberlo**, adaptando su estructura visual a la identidad, contenido e imágenes de LS45 Automotriz.

## Objetivo del sitio

Presentar los servicios principales de LS45 Automotriz en una página web clara, responsiva y fácil de navegar, permitiendo que los usuarios conozcan la empresa, revisen imágenes de referencia y accedan rápidamente a sus canales de contacto.

## Secciones del sitio

- Inicio y presentación principal.
- Sobre nosotros.
- Misión y visión.
- Servicios.
- Galería de imágenes.
- Contacto, ubicación y redes sociales.

## Mejoras aplicadas en la versión final

- Adaptación del contenido al template Oberlo.
- Organización del contenido por secciones.
- Estilos personalizados en `css/ls45-custom.css`.
- Mejora visual de la galería con cards, etiquetas y modal de imagen ampliada.
- Animación suave al hacer scroll mediante JavaScript.
- Botones de acceso rápido a servicios y contacto.
- Diseño responsivo utilizando Bootstrap.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
