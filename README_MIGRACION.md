# LS45 Automotriz - Migración a Template Oberlo

Este proyecto contiene la página web de LS45 Automotriz migrada desde el mockup desarrollado en la Unidad 2 hacia el template estándar **Oberlo**.

## Cambios principales

- Se reemplazaron los textos genéricos del template por el contenido original de LS45 Automotriz.
- Se integraron las secciones Inicio, Sobre Nosotros, Misión y Visión, Servicios, Galería, Ubicación y Contacto.
- Se mantuvo la estructura Bootstrap del template para mejorar la responsividad.
- Se creó el archivo `css/ls45-custom.css` para adaptar colores, tarjetas, galería, contacto y detalles visuales sin modificar excesivamente el template base.
- Se organizó la nueva ruta de imágenes en `images/ls45/`.
- Se corrigieron rutas sensibles a mayúsculas/minúsculas para evitar errores.
- Se agregó un modal Bootstrap para ampliar imágenes de la galería.

## Archivos principales

- `index.html`: estructura principal migrada.
- `css/style.css`: CSS original del template.
- `css/responsive.css`: CSS responsivo original del template.
- `css/ls45-custom.css`: ajustes propios de LS45 Automotriz.
- `images/ls45/`: imágenes del proyecto original reorganizadas.
